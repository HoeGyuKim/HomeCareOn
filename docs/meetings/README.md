# 회의록 (Meeting Notes)

이 폴더는 팀 회의 및 논의 내용을 기록하고 관리하는 공간입니다. 기존 `team_comment` 파일 대신, 회의별로 문서를 나누어 체계적으로 보관합니다.

## 파일 명명 규칙
- `YYYY-MM-DD_meeting.md` (예: `2026-11-16_meeting.md`)

## 회의록 기본 템플릿
```markdown
# [회의] YYYY년 MM월 DD일 N차 회의

- **일시**: YYYY.MM.DD HH:MM
- **참석자**: 권승민, 김회규, 조준혁
- **회의 방식**: Google Meet (음성/화상)

---

### 1. 회의 안건
1. 
2. 

### 2. 주요 논의 및 결정 사항
- 

### 3. 담당자별 액션 아이템
- **권승민**: 
- **김회규**: 
- **조준혁**: 
```
